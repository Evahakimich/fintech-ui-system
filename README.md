# Fintech Mobile Banking UI

## Overview
This project is a modern fintech mobile app UI focused on fast money transfers and clean UX.

## Features
- Dashboard with balance
- Transfer flow
- Transaction history
- Design system with reusable components

## Design Principles
- Minimal cognitive load
- High readability
- Consistent design tokens

## Tech
- React / SwiftUI
- Tailwind / custom styles

## Structure
- components/
- tokens/
- screens/
